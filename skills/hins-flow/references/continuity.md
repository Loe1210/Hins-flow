# Continuity and teaching

## Continuity

The change note and evidence ledger are the durable state. `/hins-flow 继续`
reconciles them with the actual repository snapshot before acting.

Create a handoff only when another task or context cannot read the canonical
record directly. Store it in the operating-system temporary directory, redact
sensitive information, and point to specs, decisions, commits, diffs, and
evidence rather than copying them. Include the intended next outcome and the
exact `/hins-flow 继续` instruction.

## Teaching branch

For a teaching outcome, first identify the user's mission and current level.
Build small source-backed lessons with one tangible win, immediate feedback,
retrieval practice, spacing, and reusable assets when the workspace already has
a teaching convention. Maintain learning state only when the user wants a
multi-session course. All learner-facing content defaults to Simplified Chinese.
